# weekly-notes

https://github.com/user-attachments/assets/5c895c35-dac9-4fa9-81e1-a468075089a8

**English** · [Norsk](#norsk)

A ready-made Obsidian vault for weekly and daily notes. The weekly note shows every day of the week, and you can click a day to create its daily note.

### Download

**[⬇ Download the English vault (weekly-notes-english.zip)](https://github.com/strombraaten/weekly-notes/releases/latest/download/weekly-notes-english.zip)**

1. Unzip the file and move the folder somewhere permanent, for example Documents. On Windows, right-click and choose **Extract All…**. Don't open the vault straight from the zip file.
2. In Obsidian, choose **Open folder as vault** and select the folder. Click **Trust author and enable plugins**.
3. Set Obsidian's language to **English (GB)**, not *English*, so that weeks start on Monday.
4. Turn on **Trigger Templater on new file creation** under *Settings → Templater*.

Everything else, including how to add the setup to a vault you already have, is in [english/README.md](english/README.md).

## Norsk

[English](#weekly-notes) · **Norsk**

Et ferdig Obsidian-vault for ukenotater og dagnotater. Ukenotatet viser alle dagene i uka, og du kan klikke på en dag for å lage dagnotatet.

### Last ned

**[⬇ Last ned det norske vaultet (ukenotater-norsk.zip)](https://github.com/strombraaten/weekly-notes/releases/latest/download/ukenotater-norsk.zip)**

1. Pakk ut ZIP-filen og flytt mappen til et fast sted, for eksempel Dokumenter. På Windows høyreklikker du og velger **Pakk ut alle…**. Ikke åpne vaultet rett fra ZIP-filen.
2. I Obsidian velger du **Open folder as vault** og peker på mappen. Trykk **Trust author and enable plugins**.
3. Bruker du Obsidian på engelsk, velger du **English (GB)** og ikke *English*, slik at uka starter på mandag. Bruker du norsk, trenger du ikke gjøre noe.
4. Slå på **Trigger Templater on new file creation** under *Settings → Templater*.

Resten, blant annet hvordan du tar oppsettet inn i et vault du har fra før, står i [norsk/README.md](norsk/README.md).
